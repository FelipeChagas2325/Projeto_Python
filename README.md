🐍 Fundamentos de Python
Este repositório reúne exercícios práticos desenvolvidos durante meus estudos de Python, com o objetivo de fortalecer a lógica de programação e compreender os principais conceitos da linguagem.

📚 Conteúdo
Os exemplos abordam temas fundamentais, como:

Tipos de dados
Entrada e saída de dados
Manipulação de strings
Métodos nativos
Operadores aritméticos, relacionais e lógicos
Estruturas condicionais (if, elif e else)
Manipulação de listas
Laços de repetição (for)
🎯 Objetivo
Consolidar os fundamentos da linguagem Python por meio de exercícios práticos, desenvolvendo uma base sólida para estudos em desenvolvimento de software, automação e cibersegurança.

🚀 Tecnologias
Python 3
📈 Aprendizados
Durante este projeto pratiquei:

Lógica de programação
Declaração e manipulação de variáveis
Conversão de tipos de dados
Operações matemáticas
Manipulação de textos
Estruturas de decisão
Manipulação de listas
Boas práticas na organização de código
📌 Este repositório faz parte da minha jornada de aprendizado em programação e será atualizado conforme avanço nos estudos.
